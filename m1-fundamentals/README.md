# M1 — Redis Fundamentals

## What I learned
- Redis is an in-memory key-value store
- Keys are strings, values can be 5+ data types
- Common commands: SET, GET, DEL, EXISTS, KEYS, TYPE, INCR, DECR

## Commands practiced
- SET / GET — store and retrieve
- EXISTS — check presence
- KEYS pattern — find keys
- INCR / DECR — atomic counter
- DEL / RENAME — manage keys
- FLUSHDB — wipe the db

## Run it
Open redis-cli and paste commands from `commands.txt`
